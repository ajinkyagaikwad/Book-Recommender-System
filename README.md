# Book-Recommender-System
Implementation of Book recommender system using K-Nearest neighbour algorithm

Introduction

This repository contains code and documentation for the book recommendation system using K-nearest neighbour algorithm. The dataset used is sourced from Kaggle.com

Objective

Perform EDA to make sense of the data, generate visualizations to see the data distribution and perform machine learning model to the scaled data

Dataset overview

The original goodreads dataset contains 11K+ records of books' data. Each record represents a unique book and includes various attributes such as author(s), average rating, number of ratings given and more

Tools Used

For the book recommendation project, the following tools and libraries were used:

Python for the libraries provided by it (scikitlearn, matplotlib, seaborn, pandas).

Pandas was instrumental in reading and handling the data.

seaborn and matplotlib libraries were used extensively to visualize the data and perform EDA.

scikitlearn to perform scaling on the data as well as perform KNN algorithm on the scaled data

Jupyter Notebooks provided an interactive environment for code development, exploration and documentation.

Data Cleaning Process

The data cleaning process involved the following steps:

Data Understanding - The dataset was thoroughly examined to understand the structure, columns and their meanings.

Data Exploration - Exploratory Data Analysis was performed to gain insights into the data, identify patterns and uncover anomalies.

Data Scaling- for the project, MinMaxScaler is used to scale the data

Machine learning algorithm- Ball Tree algorithm is used under KNN for its efficiency and fastest runtime
 
For detailed information about the book recommendation system process, please refer to the Jupyter notebooks provided in the repository
